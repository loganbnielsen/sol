## Findings

### AUDIT-068 — TypeScript showcase dependency graph is stale and vulnerable

* **Severity:** High
* **Location:** `examples/pluto/app/demo_ts/{order_svc,fulfillment_worker}/package.json`
  and `package-lock.json`
* **Evidence:** `npm ci` deprecates `prom-client@15.1.3` in favor of
  `@prometheus-io/client`. `npm audit` reports 11 advisories in the pinned
  OpenTelemetry graph, including the high-severity malformed-Jaeger-header DoS;
  `npm outdated` shows the demo on OTel 1.30/0.55 while fixed current releases
  are 2.11/0.222. The migration is a coordinated major-version change, not a
  safe lockfile-only bump.
* **Remediation:** migrate both demo units to `@prometheus-io/client`, upgrade
  the OTel packages as one compatible set, regenerate the lockfile, and retain
  build plus runtime trace/metric coverage. Add `npm audit` (or equivalent
  advisory gating) so the showcase cannot silently age back into this state.
