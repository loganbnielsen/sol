`sol-svc`: refuse a `Jwks_url` that is not `https://` at startup

**Depends on:** None.

**Finding:** FND-0053 (`internal/pipeline/audits/findings/`).

**Premise verified 2026-09-24** against `origin/main @ fd5c7e0c`: a token was verified
against keys served by `Jwks_url "http://127.0.0.1:18101/jwks.json"` through the real
`fetch_jwks_over_https`.

## Problem

`auth.mli` documents `Jwks_url` as an HTTPS URL fetched over TLS, but nothing checks
the scheme. `Https_eio` uses plain HTTP for a non-`https` URI, and the keys it returns
are trusted to verify signatures. Anyone on the network path can substitute them.

## Remediation

In `Service.Make.run`, before listening: for every route's auth and `metrics_auth`, a
`Jwks_url` must parse as an absolute `https://` URL with a host. Otherwise return
`` `Config "Jwks_url must be an https:// URL: <url>" ``, the same way a bad `PORT` or a
missing API key fails. Keep the `.mli` wording and state that it is enforced.

## Acceptance criteria

- Test: an `http://` `Jwks_url` makes `run` return a `` `Config `` error; an
  `https://` one starts.
- Mutation check: removing the check fails that test.
- Demo/example: not applicable (a startup validation); state it in completion notes.
- TS parity: record the verdict (DEC-022).

## Completion notes (2026-09-24)

Premise re-checked on the audit branch (`fd5c7e0c` + the audit commit): no scheme check
existed anywhere in `sol-svc`.

- `Service.Make.run` refuses, before listening, any route auth or `metrics_auth` whose
  `Jwks_url` is not an absolute `https://` URL with a host. It returns
  `` `Config `` naming the URL, next to the SEC-006 check.
- Tests: `http://` on a route, a scheme-less URL, and `http://` on `metrics_auth` are
  each a `` `Config `` error naming the URL; `https://` starts.
- Mutation checks (each built and failed the intended test): the check never called,
  and the check accepting any scheme.
- `auth.mli` and `sol-svc.md` state that the requirement is enforced.
- **Demo/example:** not applicable (a startup validation; every example `Jwks_url` is
  already `https://`).
- **Language parity:** not applicable. The TypeScript `svc` package does not own auth
  (`sol-typescript/packages/svc/src/index.ts:41`).
