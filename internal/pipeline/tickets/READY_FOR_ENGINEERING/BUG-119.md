**Depends on:** None.

`Sol_cli_rollback.execute` applies the reconstructed workloads with
`Sol_cli_result.map_list`, which stops on the first error. That error is returned
raw. Every other incomplete branch of the transaction appends what state was left
behind — "the current-release pointer was left unchanged" for a workload
mismatch or a prune failure, "the pointer was moved but does not read back" for a
failed pointer verification.

## Impact

When the apply of the second of three workloads fails, the first is already
carrying the restored release label while the pointer still names the bad one,
and the operator is shown only the underlying apply error. Nothing tells them the
cluster is partway restored and that retrying `sol rollback` (or redeploying) is
required. The behaviour is safe — the pointer is not moved — but the report is
not, and this is exactly the partial-failure path the rollback qualification
names.

## Remediation

Wrap the apply error in the transaction's own message: name the target release,
state that the pointer was left unchanged, and state that the workloads applied
before the failure may already carry the restored release. Keep the underlying
error text.

## Acceptance criteria

- A partial apply returns an error containing both the underlying apply failure
  and the statement that the pointer was left unchanged.
- The pointer is still not moved (existing behaviour, covered by a regression
  test).
- Demo/example: none needed — an error message, not an author-facing surface.
  Language parity: reconstruction is shared, so no per-language change.

## Completion notes

- Fixed: `execute` wraps a failed `apply` with the target release, the fact that
  some workloads may already carry the restored release, and that the pointer was
  left on the previous release. Regression:
  `rollback_transaction: a failed apply reports the incomplete rollback (BUG-119)`.
- Verification: `dune build`; `dune test cli/test/inline` (green); the
  qualification harness's partial-apply case still passes (it now also matches
  the wrapped text).
