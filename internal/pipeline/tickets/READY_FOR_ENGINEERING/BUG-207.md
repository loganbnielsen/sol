title: Resume a failed platform install with bounded installation authority

**Depends on:** None.

## Premise verified

`cli/lib/cloud/sol_cli_cloud_wiring.ml` removes bootstrap access after an install attempt, including failure. The AWS retry ran as steady-state `cluster-access` and was forbidden from platform RBAC mutations. GCP also removed access after its failed install. The GCP retry outcome has not been observed.

## Remediation

Keep removal on every exit, then make a subsequent authorized `cloud apply` reopen and verify the temporary install window before reconciling an incomplete platform. Preserve the steady-state access boundary; do not grant permanent installation rights to `cluster-access` or `operator`. Surface the original platform failure and the retry procedure separately from an authorization failure.

## Acceptance criteria

- Simulate an install failure, verify the temporary grant is removed, retry, and observe a bounded grant restored for reconciliation and removed again after success or failure.
- Test AWS and GCP lifecycle paths and a post-failure destroy.
- Example impact: none; this repairs internal cloud lifecycle. Language-parity impact: none; both languages share it.
