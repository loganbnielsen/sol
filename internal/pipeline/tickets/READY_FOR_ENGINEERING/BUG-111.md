**Depends on:** None.

## Problem

BUG-108 fixed the workspace path, which made reconciliation actually run — and exposed that nothing gated it on the deploy's **scope**. `sol up --scope=demo_ts` in `examples/pluto` is the TypeScript golden path: the scope declares only TypeScript services, and that CI job installs Node, not OCaml. Reconciliation still fired, ran `dune exec ./contract/contract.exe -- --apply`, and the deploy aborted:

```
  $ 'dune' 'exec' './contract/contract.exe' '--' '--apply'
[apply] FAILED (0.0s)
    spawn failed: create_process: No such file or directory
```

`golden-path-smoke-ts` (run `36787997464`, step 11) failed on it. Two defects in one: reconciliation is a property of the *scope* being deployed, not of the workspace directory, and a scope with no OCaml workload has no contract to reconcile — the TypeScript projection is FEAT-119's, not yet implemented.

## Remediation

Gate reconciliation on the deploy's scope:

- `scope_has_ocaml` — true unless every service in scope declares `typescript`; an undeclared language errs toward reconciling, so a hand-written `sol.yml` cannot silently skip registration.
- `ocaml_reconciliation_image` — the image to run the in-destination Job with: an explicit `ocaml` service first, then any service that is not `typescript`, else none.

`sol up`, `sol deploy`, and `sol plan` all consult the rule.

## Acceptance criteria

- A TypeScript-only scope skips reconciliation; an OCaml or mixed scope reconciles.
- `golden-path-smoke-ts` and `golden-path-smoke` both pass.
- A scope whose services do not declare a language is still reconciled.

**Demo/example coverage:** no example change; pluto's two golden paths are the regression guard (`sol up` and `sol up --scope=demo_ts`).

## Completion notes (2026-09-30)

`Sol_cli_contract.scope_has_ocaml` / `ocaml_reconciliation_image` carry the rule; `sol up` (`apply_plan`) and `sol deploy` (`contract_reconciliation`) use it, and `sol plan` skips its contract section when the target declares no OCaml service. `test_manifest_render`'s "contract reconciliation" group asserts all-TypeScript skips, OCaml reconciles, mixed reconciles, and an undeclared language reconciles.
