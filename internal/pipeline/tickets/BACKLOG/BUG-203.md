**Depends on:** None.

## Observed

`main @ d0cff2f6`'s post-merge `test` job failed in `@ci-lifecycle`, in
`framework/ocaml/sol-jobs/test/test_sol_jobs_pg.ml`:

```
FAIL lease fencing (BUG-050) › long handler renews its lease
one handler ran
  Expected: 1
  Actual  : 2
1 failed in 3.97s. 20 tests run.
```

The same content passed the PR's own `test` job (`3ffb11b0`, and `47fc2266` before it),
and the failing commit changes only markdown, so this is timing/load-sensitive rather than
a behaviour change: the test expects a long handler's lease renewal to fence a second
worker out, and under load the second worker claimed the job before the renewal landed.

## Remaining work

Determine whether the assertion races its own setup (the second claim is attempted before
the first handler's renewal is observable) or whether lease renewal can genuinely lapse
under contention; make the test deterministic in the first case, and file the lease
defect in the second.
