`DONE` is not a reliable signal: five reverted-and-never-refixed tickets sat unnoticed for three months

**Description:** EXP-021 through EXP-025 were each merged and then reverted the same evening (2026-06-13) after breaking tests (`pipeline: test failure blocked EXP-0NN` commits immediately precede each revert: `b3679a83`, `75bb534b`, `9c31e9a3`, `cdb071a9`, `33baf66d`). None were refiled, reopened, or fixed forward — all five ticket files remain in `project/tickets/DONE/` with `## Review — automated checks passed` sections describing fixes that no longer exist in `main`. Every audit/dogfood pass since (`2026-06-22_docs_audit.md`, three `code_layer_audit` runs in September 2026, `RUN_2026-09-07*` dogfood reports) evidently trusted the DONE state rather than re-verifying against source, since none caught this recurrence. This ux-audit only found it by reading current source directly and independently, then diffing against the ticket claims.

**Impact:** This repo's own `CLAUDE.md` documents `project/tickets/DONE/` as meaning "merged" — treated pipeline-wide as ground truth for "this is live in main." A revert after merge leaves no mechanism to un-DONE a ticket, so any future revert (for any reason, not just a test failure) will silently and permanently misrepresent repo state unless someone happens to read source instead of trusting the ticket. `project/tickets/DONE/` currently holds 385 entries; this class of drift could exist elsewhere undetected.

**Remediation:** Add a safeguard to the pipeline's merge/revert handling: when a merge to `main` is reverted, the revert commit should identify the original ticket (from the merge commit message or PR reference) and automatically move that ticket file from `DONE/` back to `READY_FOR_ENGINEERING/` with a note explaining the revert reason, rather than leaving it in `DONE/`. As a lower-effort interim measure, `/audit`-family skills could grep recent history for `Revert "Merge branch '<TICKET-ID>` patterns against every `DONE/` ticket ID as part of their "check previous findings" step, to catch exactly this pattern going forward.
