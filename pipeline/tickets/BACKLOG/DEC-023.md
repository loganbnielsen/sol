**Depends on:** DEC-022.

**Related:** DEC-012, DEC-013, FEAT-080, FEAT-082.

**Question:** What is the normal install/distribution story for the
`@sol/*` TypeScript packages, so that the TypeScript golden path
(FEAT-082) can actually be walked by someone outside this repository?

## Context

DEC-013 decided to reserve the npm scope now and publish later, because
distribution triggers dependency-licence obligations (INFRA-007) and no
external consumer existed. DEC-022 changes that premise: TypeScript is now
the adoption funnel, which makes distribution load-bearing rather than
optional. Today the intended experience is contradicted:

```text
README:       TypeScript is first-class!
developer:    npm install @sol/kafka
npm:          404
```

The packages are real enough to be published (built, tested, dogfooded by
`demo_ts`, CI-covered) — but they remain `"private": true` and unpublished,
so a TS developer can only consume them by cloning this repo. That is not a
golden path.

## Options

1. **Publish `@sol/kafka`/`@sol/obs` to npm** (claim the scope), gated on
   FEAT-082's golden path being coherent and INFRA-007's licence inventory
   being done.
2. **Document an in-repo install path** (npm workspace / git dependency)
   until the golden path and licence inventory are ready, so an early user
   can still get started without cloning-by-hand guesswork.
3. Keep source-only, as today.

## Decision (2026-09-15) — Option 2, with npm as the explicit target

**Chosen:** document a working interim install path *now* (option 2), and
publish the supported `@sol/*` packages to npm once **FEAT-082 establishes a
coherent TypeScript golden path** *and* **INFRA-007 clears their distribution
dependencies**. Option 3 (source-only) is rejected: DEC-022 makes TypeScript the
adoption funnel, so the README's "first-class" claim cannot sit next to a 404.

The trigger is deliberately a *destination*, not an open-ended reconsideration —
npm is where this ends up. Using an interim mechanism today does not weaken
DEC-022; it acknowledges that the product is not yet at its external-release
point:

```text
today   TS = first-class product direction   distribution = interim/dev path
target  TS = first-class usable product      distribution = normal npm packages
```

**Reconciles with DEC-013** (reserve the scope, publish when the product is
worth sharing): its two stated reasons for deferring were dependency-licence
obligations and the absence of an external consumer. The second no longer holds
(DEC-022), and the first is precisely INFRA-007's job — hence the gate rather
than a bypass.

**INFRA-007** remains the blocking prerequisite for the *publish* step; its
dependency-licence audit is not assumed away here.

## Remaining work

The decision is made; what remains is the interim path itself — README's
TypeScript section must point at an install mechanism that actually works for an
external developer (verified, not sketched), and the publish step's licence
obligation is discharged via INFRA-007.

## Acceptance criteria

- A written decision names the distribution mechanism and its trigger.
- README's TypeScript section points at a path that actually works for an
  external developer.
- Any publish step's licence obligation is addressed via INFRA-007, not
  assumed away.
