**Depends on:** DEC-022.

**Related:** DEC-012, DEC-013, FEAT-080, FEAT-082.

**Question:** What is the normal install/distribution story for the
`@sol/*` TypeScript packages, so that the TypeScript golden path
(FEAT-082) can actually be walked by someone outside this repository?

## Context

DEC-013 decided to reserve the npm scope now and publish later, because
distribution triggers dependency-licence obligations (INFRA-007) and no
external consumer existed. DEC-022 changes that premise: TypeScript is now
the adoption funnel, which makes distribution load-bearing rather than
optional. Today the intended experience is contradicted:

```text
README:       TypeScript is first-class!
developer:    npm install @sol/kafka
npm:          404
```

The packages are real enough to be published (built, tested, dogfooded by
`demo_ts`, CI-covered) — but they remain `"private": true` and unpublished,
so a TS developer can only consume them by cloning this repo. That is not a
golden path.

## Options

1. **Publish `@sol/kafka`/`@sol/obs` to npm** (claim the scope), gated on
   FEAT-082's golden path being coherent and INFRA-007's licence inventory
   being done.
2. **Document an in-repo install path** (npm workspace / git dependency)
   until the golden path and licence inventory are ready, so an early user
   can still get started without cloning-by-hand guesswork.
3. Keep source-only, as today.

## Decision Required

A decision naming the chosen option, the trigger for publishing if not
immediate, and how it reconciles with DEC-013 and INFRA-007's outstanding
dependency-licence audit. Option 3 is not acceptable once DEC-022 makes
TypeScript the adoption funnel — but the specific answer (publish now vs
documented interim path) is the owner's call, deliberately not prejudged
here.

## Acceptance criteria

- A written decision names the distribution mechanism and its trigger.
- README's TypeScript section points at a path that actually works for an
  external developer.
- Any publish step's licence obligation is addressed via INFRA-007, not
  assumed away.
